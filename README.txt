++[Number Base Convertor]++

this program was written in C. the goal was for me, a C beginner to get
more comfortable with using functions, working with arrays and ...
this program currently supports:

1.decimal to binary
2.binary to decimal
3.decimal to octal
4.octal to decimal
5.decimal to hexadecimal
6.hexadecimal to decimal
7.binary to hexadecimal
8.hexadecimal to binary

i was initially planning to do everything from scratch but kinda gave up on 
hexadecimal and just used the built in conversion method (%x). i realize
this is not anywhere close to being efficient code, but i learned a lot
from it.
